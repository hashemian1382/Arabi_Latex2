# جزوهٔ جامع عربی دوازدهم (علوم انسانی) — قالب LaTeX

قالب کامل و حرفه‌ای جزوهٔ آموزشی عربی دوازدهم انسانی (به تدریس دکتر مریم هاشمیان)
با XeLaTeX + بستهٔ `xepersian`.

## ساختار پوشه‌ها

```
arabic12-hashemian/
├── main.tex                 ← فایلِ اصلی (همین را کامپایل کنید)
├── preamble.tex             ← پیشامقدمه: بسته‌ها، فونت‌ها
├── fonts/                   ← فونت‌ها: Vazirmatn-FD (فارسی) + Amiri (عربی)
├── assets/                  ← تصاویر تزئینی (نوار و مدالیون اسلامی)
├── settings/
│   ├── colors.tex           ← پالت رنگ
│   ├── layout.tex           ← صفحه‌آرایی، سرصفحه، فهرست، دستورهای درس و تست
│   └── boxes.tex            ← جعبه‌های محتوایی (tcolorbox)
├── front/
│   ├── cover.tex            ← جلد
│   ├── intro.tex            ← مقدمه، راهنما، نمادها
│   └── toclist.tex          ← فهرست مطالب
├── lessons/
│   ├── lesson01.tex         ← درس ۱ (محتوای کامل)
│   ├── lesson02.tex         ← درس ۲ (محتوای کامل)
│   ├── lesson03.tex         ← درس ۳ (قالب آمادهٔ درج محتوا)
│   ├── lesson04.tex         ← درس ۴ (قالب آمادهٔ درج محتوا)
│   └── lesson05.tex         ← درس ۵ (قالب آمادهٔ درج محتوا)
└── back/
    ├── vocabulary.tex       ← واژه‌نامهٔ جامع الفبایی (درس ۱ و ۲ کامل + الگوی بقیه)
    ├── grammar.tex          ← مرور سریع و درسنامهٔ جامع قواعد
    ├── tests.tex            ← بانک تست‌های اضافی + پاسخنامهٔ تشریحی
    └── exams.tex            ← ۳ آزمون جامع مشابه کنکور + پاسخنامهٔ تشریحی
```

## کامپایل در Overleaf

1. در Overleaf یک «Blank Project» بسازید و همهٔ فایل‌ها را با همان ساختار آپلود کنید
   (یا کل پوشه را ZIP کرده و با Upload Project وارد کنید).
2. از منوی **Menu → Compiler** حتماً گزینهٔ **XeLaTeX** را انتخاب کنید.
3. فایل `main.tex` را دو بار کامپایل کنید تا فهرست مطالب کامل شود.

کامپایل محلی:
```bash
cd arabic12-hashemian
xelatex main.tex
xelatex main.tex
```

## دستورهای اصلی قالب

| دستور / محیط | کاربرد |
|---||
| `\Lesson{عربی}{فارسی}{حکمت عربی}{حکمت فارسی}{نقل‌کننده}` | صفحهٔ آغازین درس |
| `\JGoals{هدف ۱ \JGoalSep هدف ۲}` | جعبهٔ هدف‌های درس |
| `\Jsec{عنوان}` | سرفصل درون درس (در فهرست ثبت می‌شود) |
| `\Jsub{عنوان}` / `\Jsubsec{عنوان}` | زیرعنوان‌ها |
| `JNass` | متن درس |
| `JTarjome[عنوان]` | ترجمهٔ روان |
| `JPoem` + `\JPoemBayt{مصراع ۱}{مصراع ۲}` + `\JPNote{ن}{متن}` | شعر با پانویس |
| `JMTable` + `\JW{واژه}{معنی}{نکته}` | جدول واژه‌نامهٔ درس |
| `JGTable` + `\JGLetter{ب}` + `\SJW{واژه}{معنا}{نکته}{درس}` | واژه‌نامهٔ جامع الفبایی |
| `JQaede[گزینه‌ها]{عنوان}` | جعبهٔ قاعده |
| `JNokte` / `JDam` / `JGood` / `JMesal` / `JHadith` / `JAyat` | نکته / دام آزمون / خوب است بدانیم / مثال / حدیث / آیه |
| `JTest[عنوان]` | خودآزمایی (بدون پاسخ) |
| `JTamrin[گزینه‌ها]{شماره}{عنوان}` | تمرین کتاب |
| `JKey[عنوان]` + `\JAnswer{شماره}{متن}` | پاسخنامهٔ تشریحی |
| `\JQ{سؤال}{گ۱}{گ۲}{گ۳}{گ۴}` | تست چهارگزینه‌ای (شمارهٔ خودکار) |
| `\JQnum{ش}{سؤال}{گ۱}{گ۲}{گ۳}{گ۴}` | تست با شمارهٔ دلخواه |
| `\JResetQ` | ریست شمارهٔ تست‌ها |
| `\Jdots` / `\JdotsW{۳cm}` | جای خالی نقطه‌چین |
| `\FNmark{۱}` / `\FNfoot{۱}{متن}` | پانویس درون جعبه |
| `\jr{واژه}` / `\JWRedWord{واژه‌ها}` | واژه‌های قرمزِ کتاب |
| `\Jpart{عنوان}{زیرعنوان}{شرح}` | جلد میانی بخش‌های انتهایی |
| `\JFrontSec{عنوان}` | سرفصل بخش‌های آغازین |

## نکته‌ها

- برای ساخت «نسخهٔ بدون پاسخنامه» فقط در `settings/layout.tex` عبارت
  `\JShowKeytrue` را به `\JShowKeyfalse` تغییر دهید (جعبه‌های JKey چاپ نمی‌شوند).
- فونت‌ها به‌صورت محلی در پوشهٔ `fonts/` قرار دارند؛ نیازی به نصب فونت در سیستم نیست.
- رنگ‌ها همگی با پیشوند `J` در `settings/colors.tex` تعریف شده‌اند.
